CachyOS Benchmark

Tracks your PC's performance over time so you can see exactly what changed after an update. It runs the same set of tests every time — CPU, memory, compression, video encoding, disk, GPU, and latency — and saves each result with the kernel, NVIDIA, Plasma, and Mesa versions you had at the time.

Version 1.0.1 Linux x86_64 · CachyOS MIT License

Most benchmarks give you a single score and move on. This one is built for before and after: run it, update (kernel, NVIDIA driver, Mesa, or packages), run it again, and the What changed tab shows which packages moved and which scores got faster (green) or slower (red). Small changes that fall within normal run-to-run variation are greyed out, so you only chase real regressions. It also warns you if a run started with the PC already hot, since heat can make a run look slower than it really is. Over time that gives you hard numbers to decide whether to keep an update or roll it back.

Features

  • Repeatable ~10-minute benchmark you can re-run after every update
  • Tests: sysbench CPU and memory; 7-Zip single-thread (pinned to P-cores) and multi-thread; zstd compression and decompression; x264 1080p encoding with ffmpeg; fio disk I/O; glmark2 (OpenGL) and vkmark (Vulkan) GPU tests; cyclictest latency; peak CPU and GPU temperatures
  • Every run is logged with the kernel, NVIDIA driver, Plasma and Mesa versions so history spans real updates
  • What changed view lists packages upgraded, installed or removed since the last run (read from the pacman log) and shows which metrics moved beyond normal run-to-run noise — green faster, red slower, grey within noise. Compares against the previous run and against a saved baseline
  • Warns when a run starts hot (CPU or GPU above 50°C) and offers an optional cooldown wait
  • History and Compare tabs with charts for before/after and baseline comparisons
  • Results kept outside the app in ~/bench (results.csv plus per-run logs); location changeable with CACHY_BENCH_DATA
  • Dependency check (--check-deps) prints the exact sudo pacman -S line for any missing test tools

Requirements

  • Platform: Linux x86_64. Built and tested on CachyOS (Arch-based) with KDE Plasma 6 on Wayland. Not tested on other distros yet.
  • Python, PySide6 and matplotlib are bundled in the AppImage.
  • System test tools: sysbench, 7zip or p7zip, zstd, ffmpeg, fio, glmark2, vkmark, rt-tests, lm_sensors, util-linux, plus nvidia-smi for NVIDIA GPU temperatures.

Install & run

  1. Download CachyBench-1.0.1-x86_64.AppImage.
  2. chmod +x CachyBench-1.0.1-x86_64.AppImage
  3. ./CachyBench-1.0.1-x86_64.AppImage

Useful flags

--check-deps
--selftest
--what-changed
