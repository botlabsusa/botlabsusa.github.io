GPO Benchmark

A portable Windows app that scores a PC, or a GPO export, against Microsoft Security Compliance Toolkit baselines. See how you score in each category, drill into every setting, and save a PDF report.

Beta · 0.9.0-beta Windows x64 MIT License

This is a beta, and it's unsigned. Windows SmartScreen may warn you when you open it. Click More info, then Run anyway. You can check the SHA256 hashes below first.

Features

  • Scores this PC, or a GPO export, against Microsoft Security Compliance Toolkit baselines
  • Baselines: Windows 11 24H2, 25H2 and 26H2; Windows 10; Windows Server 2022 and 2025; Microsoft Edge; Microsoft 365 Apps
  • Category scores so you can see where you stand at a glance
  • Detailed per-setting view: expected value, your value, pass or fail
  • PDF report you can save or share
  • Read-only: it never changes your settings
  • GUI and command-line versions, single file, no installer

Requirements

  • Platform: Windows x64 (Windows 10, Windows 11, Windows Server).
  • The GUI runs as administrator so it can read local policy settings.
  • Nothing else to install. Everything is bundled.

Install & run

  1. Download the GUI zip (or the CLI zip).
  2. Unzip it anywhere.
  3. Run GpoBenchmark.exe and accept the admin prompt. For the CLI, run gpo-benchmark.exe from a terminal.
