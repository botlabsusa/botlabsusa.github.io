Botlabs Bench

Windows & Linux · v1.2.1 · MIT

A free, portable PC benchmark in one file — no installer. Test CPU, memory, storage, graphics, and network, then save HTML, CSV, Excel, and JSON reports next to the app.

CachyOS Benchmark

Linux · v1.0.4 · MIT

Tracks performance changes between system updates on CachyOS and Arch, so you can see what an update changed. Same tests every time, tagged with kernel and driver versions, plus a What changed view that flags real regressions — not just a one-off score.

View CachyOS Benchmark → Downloads

GPO Benchmark Beta

Windows · v0.9.0-beta · MIT

A portable Windows app that scores a PC, or a GPO export, against Microsoft security baselines. See category scores, check every setting, and save a PDF report. Read-only.
